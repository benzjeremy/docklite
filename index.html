Die radikal schlanke
Portainer-Alternative

Keine Lust mehr auf 250 MB RAM-Verbrauch, schwere Datenbanken und träge Interfaces, nur um kurz Ressourcen und Logs zu prüfen? Docklite wiegt unter 15 MB RAM, startet in Millisekunden und redet direkt mit deinem Docker-Socket.

⬇️ Release v1.0 herunterladen 📖 Wiki & Schnellstart ⭐ Auf GitHub ansehen

In 5 Sekunden startklar

Ein Befehl genügt – keine Container-im-Container-Schachtelung notwendig.

# Linux (AMD64) direkt ausführen:
curl -sSL https://github.com/benzjeremy/docklite/releases/download/v1.0/docklite-v1.0-linux-amd64.tar.gz | tar -xz
./docklite

# Oder via Go installieren:
go install github.com/benzjeremy/docklite@v1.0

Portainer vs. Docklite im direkten Vergleich

Warum weniger oft um Welten mehr ist.

Kriterium ⚡ Docklite (v1.0) 🐢 Portainer CE
RAM-Verbrauch im Leerlauf ca. 10 – 15 MB RAM 150 – 300+ MB RAM
Architektur & Auslieferung 1 Standalone Go Binary (Astro Frontend einkompiliert) Schweres Container-Image mit eigener Datenbank (BoltDB)
Socket-Kommunikation Direkt über /var/run/docker.sock oder Windows Pipe Komplexer API-Proxy-Layer
Echtzeit-Aktualisierung Server-Sent Events (SSE) ohne Polling-Overhead Manuelles Nachladen / Schwerfälliges Polling
Sicherheit Anti-DNS-Rebinding, Anti-CSRF, CSP, Token-Auth Oft ungesicherte Standard-Installationen
Startzeit < 50 Millisekunden 15 – 30 Sekunden Container-Boot
Plattformen Linux & Windows nativ Linux-fokussiert

Features & Kernkompetenzen

Genau das, was Entwickler und Sysadmins im Alltag wirklich brauchen.

📊

Echte Live-Ressourcen

Exakte CPU-Auslastung und bereinigter Arbeitsspeicher (cgroup v1 cache / v2 inactive_file), Netzwerk I/O (Rx/Tx) und Block I/O in Echtzeit.

📜

Integrierter Log-Viewer

Schnelles Betrachten von stdout und stderr mit automatischem Demuxing der Docker-Stream-Header, Tail-Filter und Kopierfunktion.

🕹️

Container Lifecycle Management

Container mit einem Klick starten, stoppen, neustarten oder pausieren – inklusive sauberem Shutdown-Timeout.

📡

Vollwertige REST API

Jede Funktion steht als dokumentierte JSON REST-API zur Verfügung. Perfekt für eigene Skripte, Dashboards oder Health-Checks.

🔍

Deep Container Inspect

Untersuche Umgebungsvariablen, Port-Forwardings, Mount-Volumes und Netzwerkkonfigurationen auf einen Blick im JSON-Modal.

🛡️

Security by Design

Gebaut nach strikten Sicherheitsstandards: Kein offener Port ins Netz ohne Authentifizierung, strikte Host-Header-Checks und CSRF-Schutz.
