Funktionsumfang Features

Präzise Werkzeuge für Entwickler & DevOps Precision Tools for Developers & DevOps

Alles Wesentliche, um Container zu monitoren, Logs zu analysieren und Ressourcen zu schonen. Everything you need to observe containers, inspect logs, and reclaim memory.

⚡

Direkter Unix-Socket Stream

Spricht nativ mit /var/run/docker.sock (Linux) oder der Named Pipe (Windows). Keine Zwischenserver, keine Latenz.

📊

Echtzeit SSE-Metriken

CPU-, RAM-, Netzwerk- und I/O-Statistiken werden per Server-Sent Events (SSE) verlustfrei und ressourcensparend in den Browser gestreamt.

🎮

Volle Lifecycle-Kontrolle

Starte, stoppe, pausiere oder starte Container neu mit einem Klick. Automatischer Prune-Modus entfernt verwaiste Container und Images.

📜

Live Log-Viewer

Echtzeit-Logstreaming mit Farbhervorhebung, Filterung und Autoscroll direkt im Webbrowser ohne Terminal-Blockaden.

📦

Single Standalone Binary

Backend in Go und Frontend in Astro sind in einer einzigen, statisch gelinkten Binary gebündelt. Keine externen Node.js Abhängigkeiten.

🏆

Awesome-Go Auszeichnung

Offiziell gelistet in der kuratierten Sammlung Awesome-Go in der Kategorie DevOps Tools.

Wähle dein Betriebssystem oder nutze die Go Toolchain. Select your operating system or install via the Go toolchain.

Linux (x86_64)

Tarball herunterladen, Berechtigungen setzen und Web-UI auf Wunschport starten:

tar -xzf docklite-*-linux.tar.gz
chmod +x docklite
./docklite --port 8080

Windows (x86_64)

2. docklite.exe ausführen
3. Browser öffnen auf http://localhost:8080
